How this site is made

Type

Set in Source Serif 4, whose optical sizes let the same family carry both headlines and small print, with IBM Plex Mono for labels. Both are open-source and served from this site, not from a font service.

Build

Plain HTML, CSS, and a little JavaScript. The pages are generated from a few JSON files by a small Node script, and GitHub Actions rebuilds them whenever the content changes. Hosted on GitHub Pages.

There are no analytics, trackers, or cookies. Your light or dark preference is saved only in your own browser.

Books

The bookshelf is a snapshot of my public Goodreads library, refreshed by hand. Covers are stored here, so browsing the shelf doesn’t contact Goodreads.

Blowup

An original, simplified model of an NH35 automatic movement, built with React and Three.js. Its code loads only on its own page.

Portrait

An illustration of me, in my usual hoodie. Hover over it on the homepage and it smiles back.
